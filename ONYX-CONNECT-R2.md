# Jax V5 ONYX Connect R2

## Root cause fixed
R1 connected the browser directly to `wss://eu.senpa.io:2001`. The socket opened, then the upstream closed it almost immediately (code 1005). The working ONYX files include a server-side WebSocket bridge that connects upstream with:

- subprotocol: `main`
- Origin: `http://localhost:8888`
- binary frames forwarded byte-for-byte

R2 uses the same architecture:

Browser -> `wss://<your-vercel-domain>/api/ws` -> `wss://eu.senpa.io:2001/`

The browser no longer connects directly to Senpa. Authentication, captcha, spawn, cursor and other packets remain generated by Jax and are forwarded unchanged.

## Chat
The old direct `wss://chat.delt.io/delta7?protocol=v1` connection is also routed through `/api/chat-ws` with `Origin: https://delt.io`.

## Vercel
WebSocket Functions require Fluid Compute. In Vercel open:
`Project Settings -> Functions -> Fluid Compute` and make sure it is Enabled, then redeploy.

## Logs to look for
Browser console:
`[JAX/ONYX] Game WebSocket -> wss://<domain>/api/ws ...`

Vercel Runtime Logs:
- `[JAX-PROXY] browser connected`
- `[JAX-PROXY] upstream OPEN ...`
- `[JAX-PROXY] S->C opcode=8 ...`
- `[JAX-PROXY] C->S opcode=13 ...`

No JWT contents are logged.
